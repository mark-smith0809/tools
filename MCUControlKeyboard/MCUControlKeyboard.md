1.USB-HID方案
单片机模拟USB键盘
连接方式：单片机的USB接口（如STM32的USB-DM/USB-DP引脚）通过USB线直接连接到电脑的USB口
工作原理：单片机固件实现USB HID（人机交互设备）协议，让电脑将你的设备识别为一个标准的键盘。当需要输入时，单片机直接构造并发送USB键盘协议的数据包给电脑
硬件前提：单片机支持USB设备模式
特点：即插即用，通用性最好。插上任何电脑都无需安装驱动或运行额外程序，就像一个真正的键盘

2.PC端程序+Win32 API
连接方式：单片机的串口（UART TX/RX引脚）连接到一个USB转TTL串口模块，模块再插到电脑的USB口
工作原理：电脑通过虚拟串口接收单片机发来的数据，电脑上的解析数据程序会打开这个串口，解析数据，调用Windows的SendInput API来模拟键盘按键
